# Horse Racing

**Horse Racing** is a personal rewrite of the Horse Racing Tournament Management System, created to redesign the original project with a cleaner architecture, improve maintainability, and explore a new implementation approach while preserving its core business requirements.

**Author:** [Nora](https://github.com/nguyen-nbtk05)  
**Original project:** [HorseRacing-BE](https://github.com/nuocmatParis/HorseRacing-BE) · [HorseRacing-Fe](https://github.com/nuocmatParis/HorseRacing-Fe)

> This repository is an independent rewrite and uses the original project only as a reference for business logic, features, and application flow.
